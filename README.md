# Dead_Op_3D_Godot
Its intended use it to be a coding demonstration that shows multiple different programming skills. Currently, it is at a stage where it has all the basic mechanics and features. However, I intended to continue development adding features such as making a destructible map, physics, interaction with NPCS (that use AI chat models), and procedural generation.

At the moment it is a top-down, survival, shooter game in a confined space. However, this is temporary and was done to test all the features currently added are working.
